# College Placement Drive and Student Application Tracker

## Problem

The placement cell manages company drives manually, making it difficult to track applications and placement status.

---

## Objective

Develop a web application to manage placement drives and student applications efficiently.

---

- Flask
- SQLite
- HTML
- CSS

- Company

- Status History
